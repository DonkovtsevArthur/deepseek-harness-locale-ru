# Русский языковой пакет для DeepSeek Harness

**deepseek-harness-locale-ru** — языковой пакет (language pack) для веб-интерфейса [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): добавляет **Русский** в переключатель языков (Settings → General → Language) и переводит интерфейс на русский язык.

Переведено **2 909 строк** в **64 словарях**: чат, диалог, настройки, расписание, файловый менеджер, плагины, терминал, субагенты и другие разделы.

## Установка

Пакет ставится как обычный внешний бандл профиля DeepSeek Harness.

### Через CLI (рекомендуется)

```bash
dsh plugin --profile desktop add deepseek-harness-locale-ru
```

Или напрямую из GitHub:

```bash
dsh plugin --profile desktop add github:DonkovtsevArthur/dsh-locale-ru
```

Для другого профиля замените `desktop` на его имя. Если у вас tarball-файл:

```bash
dsh plugin --profile desktop add /путь/к/deepseek-harness-locale-ru-1.0.0.tgz
```

### Через интерфейс

Откройте **Plugins** (боковая панель) → **Install external bundle** и укажите:

```
deepseek-harness-locale-ru
```

## Включение языка

1. Перезагрузите страницу веб-интерфейса (при необходимости — перезапустите приложение).
2. Откройте **Settings → General → Language** → выберите **Русский**.

Выбор сохраняется в настройках профиля и применяется сразу.

Нюансы:

- Непереведённые строки (если появятся в новых версиях) автоматически откатываются на английский.
- Служебные значения настроены корректно: код локали `ru-RU` для дат, русские разделители чисел.
- Для счётных единиц использованы сокращения («дн.», «мин.», «сек.») — система поддерживает только две формы склонения, а русскому нужно три.
- Приветственное окно и диалог обновления (отдельные окна приложения) остаются на английском — они вне системы локализации веб-интерфейса.

## Совместимость

Разработано и проверено на DeepSeek Harness **0.2.1-rc.5**. Пакет не накладывает ограничений на версию (совместим с любыми), но новые версии приложения могут добавить строки, которых нет в словаре, — они будут показаны на английском.

## Как это устроено

Пакет — клиентский плагин в формате DeepSeek Harness bundle:

- `client.js` — регистрирует язык `ru` (fallback — `en`) и словари через сервис `locale`;
- `cordis.patch.yml` — включает плагин в композицию профиля;
- `locale/*.json` — отображаемые название и описание в списке плагинов.

Технически: `ctx.locale.addLanguage({ id: 'ru', label: 'Русский', fallback: 'en' })` + `ctx.locale.register(<namespace>, 'ru', <словарь>)` для каждого раздела интерфейса. Это штатный механизм языковых пакетов, описанный в документации пакета `@deepseek-ai/dsh-client-locale`.
